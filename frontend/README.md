# Альфа Курс — интерфейс (Telegram Mini App / веб)

Фронтенд MVP «Альфа Курс»: необязательная анкета, выдача до трёх карточек
с причинами рекомендации и следующим шагом, холодный старт и честные
состояния при нехватке данных (P07–P09).

Работает в двух режимах без изменения кода:

- **внутри Telegram** как Mini App (SDK подключается в `index.html`);
- **в обычном браузере** — тот же SPA, полностью функционален.

## Быстрый старт

```bash
cd frontend
npm install
npm run dev
```

Откроется `http://localhost:5173`. По умолчанию включён **мок-режим**
(`VITE_USE_MOCK=true` в `.env.example`) — фронт работает без бэкенда
на синтетических данных.

## Подключение к Go API

1. Скопировать `.env.example` в `.env` и выставить `VITE_USE_MOCK=false`.
2. В dev-режиме запросы `/api/*` проксируются на `http://localhost:8080`
   (см. `vite.config.ts`). Для продакшена задать `VITE_API_BASE`.

Используемые методы (контракт — раздел 5 документа для разработчиков):

| Метод | Назначение |
|---|---|
| `GET /api/meta` | справочники анкеты |
| `POST /api/recommendations` | подборка: `profile` **или** `demo_profile_id` (одновременно не передаются) |
| `GET /api/demo-profiles` | демо-профили P01–P10 |
| `GET /api/health` | доступность сервиса |

## Запуск внутри Telegram (для демо)

1. Поднять туннель до dev-сервера или задеплоить сборку (`npm run build`) на HTTPS-хостинг:
   ```bash
   npx ngrok http 5173
   ```
2. В Telegram: `@BotFather` → `/newapp` (или Bot Settings → Menu Button) →
   указать HTTPS-URL приложения.
3. Открыть бота → кнопка запускает Mini App.

Вне Telegram SDK Telegram недоступен — интерфейс это обрабатывает
(`isTelegram=false`), никаких ошибок не возникает.

## Экраны и состояния

- **Анкета** — задача, стадия, сфера, опыт, формат помощи. Все поля
  необязательные, есть «Пропустить анкету» (холодный старт, R3).
- **Демо-профили P01–P10** — переключатель для проверки сценариев из кейса.
- **Выдача** — до 3 карточек: тип, статус доступа (`free/paid/unknown`),
  безопасное описание, причины («по вашей задаче», «для начального уровня»…),
  следующий шаг. Бейдж режима: `personalized / topic / starter / fallback`.
- **Пустое состояние** (P09) — честное сообщение без выдуманных карточек.
- **Ошибки** — `400 INVALID_INPUT`, `503 DATA_UNAVAILABLE`, сетевой сбой:
  понятный текст + повтор запроса. Ошибка не маскируется под «нет совпадений».

## Мок-данные

`src/api/mock.ts` содержит синтетический каталог и упрощённую имитацию
правил ранжирования (4T + 2M + S + E + I) **только для разработки UI**.
Реальная логика будет в Go-сервисе; названия и ID материалов в моках
демонстрационные, при подключении бэкенда моки отключаются переменной
`VITE_USE_MOCK=false`.

## Что согласовать командой (журнал решений)

- Стек интерфейса: Vite + React + TypeScript (нужно подтверждение Саши и Ильяса).
- Telegram SDK как внешняя зависимость (ограничение кейса по внешним API учтено:
  передаётся минимум данных, `initData` на сервере не валидируется в MVP).
- Для размещения Mini App требуется бот-обёртка (кнопка запуска) — это
  технический хостинг интерфейса, а не функциональность трека 2.
