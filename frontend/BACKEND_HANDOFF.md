# Интеграция интерфейса и API

Контракт — `api/openapi.yaml`. Mini App и браузерный интерфейс используют один API через `/api`. Полные тексты остаются на сервере.

## Подбор материалов

| Запрос | Поведение |
| --- | --- |
| `{}` или `{"profile":{}}` | До трёх стартовых материалов; локальная разметка необязательна |
| Только стадия или опыт | Общая подборка с сообщением о недостатке подтверждённых признаков |
| `{"profile":{"task_id":"finance"}}` | Подбор по готовой теме |
| `{"query":"Как привлечь покупателей?"}` | Поиск по свободному тексту через внутренний Python-сервис |
| `{"demo_profile_id":"P02"}` | Подготовленный профиль; его нельзя совмещать с query, profile или history_profile_id |
| `{"history_profile_id":"H02","query":"Как привлечь покупателей?"}` | Подбор с обезличенной историей исходной БД |

Неясный текст возвращает `200` с пустым `items` и `QUERY_UNCLEAR`. Отсутствие совпадений — `NO_MATCHES`. Интерфейс показывает уточнение вместо случайных карточек.

## История

`GET /api/history-profiles` возвращает доступные H01–H03 и счётчики взаимодействий. Это демонстрационные сценарии из исходной базы, а не история текущего посетителя. Исходные UserId не передаются в браузер.

P10 использует синтетическую историю из необязательной локальной разметки. Без неё ответ содержит `HISTORY_UNAVAILABLE`.

Стадия и опыт пока не размечены у материалов и не повышают их позиции. Формат и доступные признаки сферы учитываются. Собственного журнала показов, кликов и отметок изучения нет.

## Углубление темы

После основной выдачи каждая карточка запрашивает `POST /api/deepening`. Передаются material_key, исходный текст или демо-профиль, сценарий истории и ключи уже показанных карточек.

Ответ содержит до двух более подробных материалов. Связь подтверждается содержимым статьи или разделом программы курса. Если подходящего продолжения нет, блок скрыт; ошибка дополнительного поиска не убирает основную выдачу.

Ссылки основных карточек и углубления используют Telegram WebApp.openLink внутри Mini App и обычные ссылки в браузере. Telegram BackButton возвращает к заполненному запросу.

## Ошибки и отмена

API-клиент проверяет структуру JSON для всех ответов. На новый подбор предыдущий запрос отменяется; при уходе с результатов отменяются запросы углубления. Таймаут клиента — 25 секунд.

`400` содержит error.code и error.message. Недоступность данных даёт `503`; прокси также может вернуть `502` или `504`. Ошибка показывается пользователю без автоматической замены реального каталога моками. Учебные примеры включаются только явно через `VITE_USE_MOCK=true`.

## Перед публикацией

1. Собрать frontend: `npm --prefix frontend run build`.
2. Обновить готовую версию для бота: `npm --prefix bot run sync-web`.
3. Проверить пустой профиль, свободный текст, H02, углубление и возврат к запросу.
4. Проверить доступность API через адрес Mini App: работающая страница сама по себе не подтверждает доступность API.

Для Docker Compose сборку интерфейса выполняет Dockerfile. Render использует готовую папку `bot/web`, поэтому её нужно обновлять вместе с изменениями frontend.
