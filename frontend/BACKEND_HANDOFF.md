# Вопросы к бэкенду для финальной проверки Mini App

Проверено 15 ноября 2026 на локальной базе. Go-код не менялся.
Для запуска восстановлен Docker и добавлена локальная разметка существующих
материалов; она хранится в игнорируемом `data/catalog_curation.json` и не публикуется.

## Холодный старт

`POST /api/recommendations` с `{}` или `{"profile":{}}` должен поддерживать
осмысленный сценарий пропуска анкеты. При первом аудите P07 возвращал
пустой `items`: в локальном файле отсутствовал `starter`.

После наполнения локальной разметки проверено: `{}` и P07 возвращают три реальных
материала в режиме `starter`. На другом компьютере для такого же сценария нужна
своя проверенная разметка; закрытый файл не передаётся через публичный Git.
Если API возвращает пустой результат, интерфейс показывает именно его.

## История и персональные признаки

- Изначально P10 возвращал `HISTORY_UNAVAILABLE`. Теперь локально есть
  синтетическая история на существующих материалах: завершённый исключается,
  положительный сигнал учитывается. Реальные истории пользователей не загружались.
- Изменение только стадии и опыта в двух запросах по `finance` не меняло выдачу.
  Уточнить, какие признаки реально доступны для демонстрации.
- P09 по задаче `export` возвращал три материала. Для проверки пустого состояния
  нужен отдельный воспроизводимый сценарий; P09 не гарантирует его на реальных данных.

## Контракт

Сохраняем `api/openapi.yaml` источником контракта:

- `GET /api/meta`: tasks, stages, industries, experience, help_modes.
- `GET /api/demo-profiles`: массив профилей P01–P10.
- `POST /api/recommendations`: профиль либо demo_profile_id, до трёх карточек.
- `400`: вложенные `error.code`, `error.message`, при необходимости fields.
- `503`: недоступность данных. Успешная пустая выдача остаётся ответом `200`.

Интерфейс проверяет структуру JSON и отображает причины и действия из ответа.
Сбой соединения и ответы прокси 502/504 обработаны на стороне фронтенда.
Полные тексты материалов в Mini App не требуются.

## Для живой демонстрации

Нужно подтвердить рабочий адрес API, доступность ссылок и ожидаемые результаты
для пустого профиля, P02/P03/P04 и P10. Текущий облачный Mini App зависит от
работающего локального API и туннеля; доступность самой страницы не подтверждает
доступность рекомендательной системы.
