# Бот запуска Mini App «Альфа Курс»

Минимальный бот-обёртка: по `/start` присылает кнопку, которая открывает Mini App
внутри Telegram, и регистрирует постоянную кнопку меню слева от поля ввода.

**URL в BotFather вводить не нужно.** Бот сам вызывает `setChatMenuButton`
и передаёт inline-кнопку `web_app` через Bot API — это обходит ошибку
`Please send me a valid URL. https is required`.

Никаких зависимостей: Node.js 20.6+ и встроенный `fetch`.

## Запуск за 3 шага

### 1. Токен

BotFather → `/mybots` → выбрать своего бота → **API Token** → скопировать.

```bat
cd c:\hack_alfa\bot
copy .env.example .env
```

Открыть `bot\.env` и вписать токен в `BOT_TOKEN`.

### 2. Публичный HTTPS-адрес фронтенда

Telegram открывает Mini App только по публичному `https://`.

**Вариант А (рекомендуется, постоянный адрес):**
1. `cd c:\hack_alfa\frontend && npm run build` (папка `dist` уже собрана);
2. открыть https://app.netlify.com/drop и перетащить туда папку `frontend\dist`;
3. получить `https://xxxx.netlify.app` и вписать в `WEBAPP_URL`.

**Вариант Б (локальная проверка через туннель):**
```bat
cd c:\hack_alfa\frontend
npm run preview
:: во втором терминале:
cloudflared tunnel --url http://localhost:4173
```
Взять из вывода `https://xxxx.trycloudflare.com` и вписать в `WEBAPP_URL`.
Туннель должен быть запущен, пока тестируешь.

### 3. Старт бота

```bat
cd c:\hack_alfa\bot
npm start
```

В консоли должно появиться:
```
[bot] кнопка меню зарегистрирована: https://xxxx.netlify.app
[bot] слушаю сообщения. Отправьте /start в чат с ботом.
```

Открой чат с ботом → `/start` → кнопка «Открыть Альфа Курс» → Mini App.

## Команды

| Команда | Действие |
|---|---|
| `/start` | приветствие + кнопка запуска |
| `/app` | ещё раз прислать кнопку |
| `/help` | список команд |

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| `BOT_TOKEN не задан` | нет `bot/.env` или пустой токен — скопируй `.env.example` и заполни |
| `Telegram API ...: Unauthorized` | неверный токен (взят от другого бота или с пробелом) |
| `кнопка меню не зарегистрирована` | `WEBAPP_URL` не публичный HTTPS (localhost/http не подходят) |
| `/start` присылает текст без кнопки | то же: поправь `WEBAPP_URL` и перезапусти бота |
| Кнопка есть, но Mini App не открывается | адрес недоступен снаружи: проверь, что сайт открывается в браузере на телефоне по мобильному интернету |
| `Conflict: terminated by other getUpdates request` | запущено два экземпляра бота — останови лишний |

## Ограничения MVP

- long polling, без webhook и без БД — состояние не хранится;
- `initData` от Telegram на бэкенд пока не отправляется (для трека 1 не требуется);
- уведомления и напоминания не реализованы (это функциональность трека 2, в выбранный MVP не входит).
