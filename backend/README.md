# Альфа-Курс

Backend рекомендаций: Go, PostgreSQL и подготовка текстовых оценок в Python. Пользователь выбирает задачу и параметры профиля, API возвращает до трёх материалов с объяснениями и ссылками. Произвольного текстового запроса пока нет.

## Как работает подбор

1. При старте Go загружает каталог одной read-only транзакцией и закрывает пул PostgreSQL. Запросы работают с каталогом в памяти.
2. Поисковое представление включает названия, описания, темы, теги, категории, текстовые блоки и названия вложений. Уроки вложены в курсы; скрытые уроки не индексируются. Бинарные вложения не распознаются, аудио и видео не транскрибируются.
3. Python заранее рассчитывает TF-IDF для восьми задач анкеты. Общий словарь и IDF, отдельная нормализация групп полей: метаданные 0.7, основной текст 0.3, подписи и ссылки до 0.05. Реклама сохраняется в нормализованных данных, но не влияет на поиск.
4. Go проверяет версию и отпечаток документов и задач в файле оценок. Отсутствующий, неполный или устаревший файл блокирует запуск до открытия HTTP-порта.
5. Подбор исключает hidden/unknown и завершённые материалы. Direct-разметка имеет приоритет; прочие материалы допускаются по broader-разметке или текстовой оценке от 0.1. Профиль и история усиливают допустимые результаты. Неизвестные признаки не дают бонусов; платность и рейтинг не повышают позицию.
6. Одинаковые карточки с совпадающими названием и подтверждённой ссылкой не повторяются. Объяснения формируются из использованных признаков.

Все семь видов материалов участвуют в поиске, включая записи без тем и ручной разметки. Формулировки задач находятся в `backend/internal/service/recommendation/query.go`. Веса и порог — начальные настройки, а не вероятности полезности. B0 использует соответствие задаче и ключ, без текстовых и персональных сигналов.

Локальный `catalog_curation.json` содержит проверенные direct-привязки, starter и синтетическую историю P10. Привязки проверяются по ключу и хешу названия. В публичном примере ID вымышленные: с ним подбор по задачам работает, starter пуст, P10 сообщает об отсутствии истории. Для полного демо нужен проверенный локальный файл. Пустое значение `CATALOG_CURATION_PATH` отключает разметку; отсутствующий файл по непустому пути вызывает ошибку.

Стадия бизнеса и опыт материалов пока неизвестны. Реальная история пользователей не загружается. 

## Структура

- `backend/` — Go API, загрузка и нормализация каталога, правила подбора.
- `ranking/` — TF-IDF, русский Snowball и сравнение выдачи с baseline.
- `api/` — OpenAPI 3.0.4, настройки генерации Go-сервера.
- `deploy/postgres/` — восстановление БД из локального backup.
- `data/` — синтетический пример разметки; реальные данные и подготовленные файлы исключены из Git.

Веб-интерфейс находится в отдельной ветке `front`.


## Локальная разработка

Нужны Go 1.27.0+, Task, Python 3.12–3.13 и uv. Приложение автоматически читает `.env` из текущего каталога или, если его там нет, из родительского. Уже заданные переменные окружения имеют приоритет. Отсутствие `.env` допустимо, если настройки переданы через окружение. Из корня, после настройки БД и локальной разметки:

```bash
task openapi:generate
(cd backend && go run -mod=readonly ./cmd/catalog-export --documents-only)
uv sync --project ranking --frozen
uv run --project ranking --frozen python ranking/prepare_text.py data/ranking_catalog.json
task run
```

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DATABASE_URL` | Подключение pgx | Обязательна |
| `HTTP_ADDR` | Адрес HTTP | `127.0.0.1:8080` |
| `STARTUP_TIMEOUT` | Подключение и подготовка каталога | `30s` |
| `SHUTDOWN_TIMEOUT` | Завершение активных запросов | `10s` |
| `CATALOG_CURATION_PATH` | Проверенная разметка и демо-история | `../data/catalog_curation.json` из `backend/` |
| `TEXT_SCORES_PATH` | Подготовленные текстовые оценки | `../data/ranking_text_scores.json` из `backend/` |

## API

Контракт: [api/openapi.yaml](../api/openapi.yaml).

| Метод и путь | Результат |
|---|---|
| `GET /api/health` | Готовность сервиса |
| `GET /api/meta` | Варианты анкеты |
| `GET /api/demo-profiles` | Десять синтетических профилей |
| `POST /api/recommendations` | До трёх карточек, причины и ограничения |

```bash
curl -H 'Content-Type: application/json' \
  -d '{"profile":{"task_id":"finance","help_mode":"tool"},"limit":3}' \
  http://127.0.0.1:8080/api/recommendations
```

Вместо `profile` можно передать `demo_profile_id`, например `P02`. Совместная передача запрещена. Пустой объект запрашивает стартовую подборку. Неверные поля и значения дают 400; отсутствие совпадений — 200 с пустым `items`. Карточка содержит ключ, вид, название, описание до 300 символов, доступ, ссылку, причины и действие. Полные тексты и внутренние оценки не возвращаются.
